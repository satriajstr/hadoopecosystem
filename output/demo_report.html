02 / Registri imunisasi

21 baris awal → 18 anak kohort 2023 yang sudah eligible → 11 anak belum menerima dosis 3.

Provinsi_B

Selatan

0.00%

Cakupan dosis 3: 0/6 anak

Dropout: N/A (D1 = 0)

Provinsi_A

Utara

50.00%

Cakupan dosis 3: 3/6 anak

Dropout: 40.0%

Provinsi_A

Tengah

66.67%

Cakupan dosis 3: 4/6 anak

Dropout: 0.0%

Interpretasi: Selatan mempunyai cakupan terendah. Utara juga memperlihatkan kehilangan kelanjutan dosis. Tengah memiliki dropout 0%, tetapi masih ada anak yang belum memulai dosis pertama.

Cakupan = D3 / seluruh anak eligible × 100%. Dropout = (D1 − D3) / D1 × 100%. N/A berarti denominator nol, bukan dropout 0%. Angka menggambarkan dataset contoh, bukan estimasi populasi wilayah.

"""Hadoop Streaming: satu pasangan (kata, 1) untuk setiap token."""
import sys

for line in sys.stdin:
    # Sama dengan modul: token dipisahkan whitespace, case-sensitive.
    for word in line.strip().split():
        print(f"{word}\t1")
code/reducer.py
#!/usr/bin/env python3
"""Input harus sudah dikelompokkan/diurutkan berdasarkan key oleh shuffle."""
import sys

current_word = None
total = 0
for line in sys.stdin:
    if not line.strip():
        continue
    word, count = line.rstrip("\n").split("\t", 1)
    if current_word is not None and word != current_word:
        print(f"{current_word}\t{total}")
        total = 0
    current_word = word
    total += int(count)

if current_word is not None:
    print(f"{current_word}\t{total}")
native/coverage.sql
-- Query yang sama dieksekusi oleh SQLite lokal dan disediakan untuk Hive.
-- Satu baris = satu anak; hanya kohort 2023 yang sudah eligible dosis ketiga.
WITH cohort AS (
    SELECT * FROM vaccinations
    WHERE birth_year = 2023 AND dose3_due = 1
)
SELECT province, district,
       COUNT(*) AS eligible_children,
       SUM(dose1) AS dose1_children,
       SUM(dose3) AS dose3_children,
       ROUND(100.0 * SUM(dose3) / COUNT(*), 2) AS coverage_pct,
       ROUND(100.0 * (SUM(dose1) - SUM(dose3))
             / NULLIF(SUM(dose1), 0), 2) AS dropout_pct,
       SUM(CASE WHEN dose3 = 0 THEN 1 ELSE 0 END) AS missed_dose3
FROM cohort
GROUP BY province, district
ORDER BY coverage_pct ASC, province ASC, district ASC;
native/etl_imunisasi.pig
-- Input CSV tanpa header. Parameter diisi dari folder HDFS run_hadoop.sh.
-- Dataset demo sudah divalidasi (ID unik, flag 0/1, dose3 <= dose1).
raw = LOAD '$INPUT' USING PigStorage(',') AS (
    child_id:chararray, province:chararray, district:chararray,
    birth_year:int, dose3_due:int, dose1:int, dose3:int
);
cohort = FILTER raw BY birth_year == 2023 AND dose3_due == 1;
missed = FILTER cohort BY dose3 == 0;
result = FOREACH missed GENERATE child_id, province, district, dose1, dose3;
STORE result INTO '$OUTPUT' USING PigStorage(',');
